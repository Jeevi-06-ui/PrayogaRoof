========================================================================
  PRAYOGAPROOF – Interactive Mathematics Learning Lab (Classes 10–12)
  100% Offline Standalone Package
========================================================================

HOW TO OPEN & RUN:
------------------
1. Double-click "LAUNCH_PRAYOGAPROOF.bat".
2. Your web browser (Edge, Chrome, Brave, etc.) will open automatically to:
   http://localhost:5173

NO INTERNET NEEDED:
-------------------
All assets, animations, Canvas visual engines, voice narration, math labs,
and diagnostic question banks are locally bundled inside this single folder.
You can disconnect Wi-Fi / Ethernet completely and the entire application
will continue running flawlessly.

FOLDER CONTENTS:
----------------
- LAUNCH_PRAYOGAPROOF.bat  : 1-Click double-clickable Windows launcher
- server.js               : Zero-dependency local offline web server (uses built-in Node.js)
- index.html              : Application entry point
- assets/                 : Bundled JavaScript, CSS, 2D/3D visual rendering engines
- icons/                  : PWA vector application icons
- manifest.json           : Offline PWA manifest for desktop installation
- sw.js                   : Offline Service Worker caching engine

FEATURES INCLUDED:
------------------
- Class 10, 11, and 12 complete Mathematics curriculum
- Animated concept video proofs with play, pause, replay, and speed controls
- Synchronized spoken voice narration for all lessons
- Interactive Math Lab with parameter experimentation and real-time Auto-Fix
- Live Diagnostic Quiz & Step Grader with automatic voice explanations on wrong answers
- JEE Main & Advanced Practice Arena
- Oral Viva Voce examiner
- Bookmarks & Formula repository
- Gamification with daily streaks, XP, and milestone badges
========================================================================
